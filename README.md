# Mini-batch-k-Means-Clustering

The objective of the project is to implement the Mini-Batch K-Means algorithm within a parallel computing framework using ..., with a focus on scalable clustering of large datasets (...). The algorithm is designed to efficiently approximate standard K-Means by updating cluster centroids using randomly sampled mini-batches, enabling reduced computational cost while preserving clustering quality. The implementation is evaluated in a distributed setting to assess performance, convergence behaviour, and scalability.

The project includes data preprocessing, exploratory analysis, parallel algorithm design and implementation in Spark, performance evaluation, and analysis of clustering results.
