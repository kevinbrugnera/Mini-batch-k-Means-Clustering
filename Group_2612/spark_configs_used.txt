SPARK SESSION CONFIGURATIONS USED

=======================================================
1. Topology Benchmark
=======================================================

NUM_PARTITIONS = 16

- Thin (16 Executors - 1 core each)

spark-submit \
  --master spark://$MASTER_IP:7077 \
  --driver-memory 2G \
  --executor-memory 1G \
  --conf spark.executor.memoryOverhead=750M \
  --conf spark.memory.fraction=0.8 \
  --conf spark.memory.storageFraction=0.7 \
  --total-executor-cores 16 \
  --executor-cores 1 \
  --conf spark.eventLog.enabled=true \
  --conf spark.eventLog.dir=file:///tmp/spark-events \
  --py-files functions.py \
  $TARGET_SCRIPT

- Balanced (8 Executors - 2 core each)
